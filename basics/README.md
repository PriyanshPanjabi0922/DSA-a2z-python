# Basics

This folder contains the foundational concepts and problems I worked through while following Striver's A2Z DSA course.

## Topics Covered

- Basic programming concepts
- Pattern problems
- Basic Mathematics
  - Palindrome
  - Armstrong Number
  - Prime Number
  - Other basic number problems
- Recursion
  - Palindrome using recursion
  - Basic recursion practice
- Hashing
  - Array hashing
  - Character hashing
  - Frequency counting
  - Highest and lowest frequency element

## Learning Approach

For the earlier topics, I used Striver's explanations and examples to understand the concepts and practice their implementation in Python.

From the later topics, I am focusing more on independently converting the algorithmic idea into Python, debugging my implementation, and documenting what I learn.

## Goal

Build strong fundamentals in problem-solving, recursion, hashing, and Python implementation before moving deeper into DSA.
