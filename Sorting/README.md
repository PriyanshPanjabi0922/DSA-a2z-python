# Sorting

This folder contains the sorting algorithms I learned while following Striver's A2Z DSA course and implemented in Python.

## Topics Covered

- Selection Sort
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Bubble Sort using recursion
- Insertion Sort using recursion

## Learning Approach

I first learn the algorithm and its intuition from Striver's explanations.

Then I try to implement the algorithm in Python myself rather than directly copying the implementation.

When my implementation does not work, I debug it by identifying whether the issue is:
- Logic
- Python implementation
- Recursion
- Boundary conditions
- Complexity or optimization

## Goal

Understand how different sorting algorithms work, how their approaches differ, and how to implement them correctly in Python.

The focus is on understanding the algorithm rather than simply memorizing code.
